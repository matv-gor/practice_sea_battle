# Sea Battle

Морской бой на C++ с графикой на SFML. Два игрока на одном экране (hot seat).

## Что готово

### Логика
- **Ship** — хранит позиции, здоровье, проверка попадания и уничтожения
- **Board** — сетка 10×10, расстановка кораблей, выстрел, ореол вокруг убитого корабля, проверка конца игры
- **Game** — две доски, смена ходов, фазы игры (Placement / Battle / Finished), делегирование расстановки и выстрелов

### Прочее
- Базовое окно SFML с отрисовкой двух пустых сеток
