# Sea Battle

Настольный Морской бой на двух игроков (hot-seat) — C++20 + SFML 3.0.

## Быстрый старт

```bash
git clone <repo>
cd practice_sea_battle
cmake -S . -B build
cmake --build build
./build/test
```

SFML 3.0 скачивается автоматически через CMake FetchContent.

**Требования:** CMake 3.24+, компилятор с поддержкой C++20.

## Как играть

1. **Расстановка** — каждый игрок расставляет флот по очереди. Второй игрок не видит доску первого благодаря экрану передачи хода.
2. **Бой** — игроки по очереди кликают по вражеской доске. При попадании право хода сохраняется.
3. **Победа** — тот, кто уничтожил весь вражеский флот, побеждает.

### Управление

| Действие | Способ |
|---|---|
| Выбрать размер корабля | Клавиши `1`–`4` или кнопки в панели |
| Повернуть корабль | Клавиша `R` или кнопка `Horizontal/Vertical` |
| Поставить корабль | Левый клик на доске |
| Выстрелить | Левый клик на вражеской доске |
| Выйти | `Esc` |

### Флот

| Размер | Количество |
|---|---|
| 4 клетки | 1 |
| 3 клетки | 2 |
| 2 клетки | 3 |
| 1 клетка | 4 |

## Архитектура

```
practice_sea_battle/
├── main.cpp
├── backend/
│   ├── ship.hpp / ship.cpp      — корабль: позиции, попадания, уничтожение
│   ├── board.h / board.cpp      — сетка 10×10, расстановка, выстрел, ореол
│   ├── game.h / game.cpp        — две доски, смена ходов, фазы игры
│   ├── Coordinate.h             — структура координаты
│   └── constants.h
└── frontend/
    ├── app.h / app.cpp          — главный цикл SFML, обработка событий
    ├── ui_logic.h / ui_logic.cpp — вспомогательная логика UI
    ├── ui_render.h / ui_render.cpp — отрисовка досок, кнопок, текста
    └── ui_types.h               — типы и константы UI
```

**Фазы игры:** `Placement → Handoff → Battle → Finished`

**Коды клеток доски:** `0` пусто · `1` ореол · `2` корабль · `3` уничтожен · `4` промах

## Стек

- C++20
- SFML 3.0
- CMake 3.24+

Сборка использует `-Wall -Wextra -Werror -Wpedantic`. Доступна цель `clang-format` для проверки форматирования.
